## Project Overview
5-page responsive website for Delicious Bakery in Cape Town CBD. Purpose is to increase online presence, show products, and get customer enquiries.

## Pages
1. index.html - Home with hero image and branding
2. about.html - Bakery story and history
3. services.html - Products (bread, sourdough, cakes, pastries) with images
4. enquiry.html - Enquiry form for orders
5. contact.html - Map, hours, contact details

## Rubric Requirements Covered (For Lecturer)
- Semantic HTML5: header, nav, main, section, footer on all pages
- SEO: meta description, keywords, viewport, title on all 5 pages
- Navigation: Same navigation with 5 links on all pages (as required)
- CSS: External stylesheet css/style.css linked correctly
- Responsive: @media query max-width 600px (menu stacks on mobile)
- Images: Responsive with max-width 100% and alt text
- Form: enquiry.html with required validation
- Comments: Student number St10502981 and section purpose in HTML and CSS
